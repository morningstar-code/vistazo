# Try Vistazo here

With Vistazo installed, rest the pointer on any file in this folder (no clicking):

| File | What you'll see |
| --- | --- |
| [`hello.lua`](hello.lua) | Lua with syntax highlighting |
| [`config.json`](config.json) | Minified JSON, formatted for you (toggle back to the source) |
| [`players.csv`](players.csv) | A CSV file shown as a table |
| [`notes.md`](notes.md) | Rendered Markdown: table, task list, alert |
| [`logo.png`](logo.png) | An image with its dimensions |
| [`nested`](nested) | A folder: hover a file inside its preview to go one level deeper |

Links to specific lines work too, like the ones people paste in issues:
[`hello.lua`, lines 8 to 14](hello.lua#L8-L14).
