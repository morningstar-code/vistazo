# Security policy

Vistazo renders content from arbitrary GitHub repositories inside github.com, so security reports are
taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting instead:
[Report a vulnerability](https://github.com/morningstar-code/vistazo/security/advisories/new).

Include the steps to reproduce (a public repository or file that triggers the problem is ideal) and the
browser version. You can expect a first answer within a week.

## Scope

Examples of what counts: script execution or HTML injection from repository content (file names,
Markdown, SVG), requests sent anywhere other than GitHub, or leaks of private repository content.

## Supported versions

Only the latest release receives fixes.
